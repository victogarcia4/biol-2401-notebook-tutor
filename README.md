An active, interactive learning repository designed for **BIOL 2401 Anatomy & Physiology I** students. This dual-purpose hub integrates **Google NotebookLM** custom Student Learning Outcome (SLO) notebooks with **Google Gemini** interactive AI tutors across all 12 core chapter modules.

---

## 🌟 Overview & Educational Objectives

Developed by **Dr. Victor Garcia Martínez** (Professor of Anatomy & Physiology, Lone Star College), this learning portal combines clinical relevance with AI-enhanced instructional design. It provides a structured, gamified self-study ecosystem aligned with formal learning outcomes and Bloom's taxonomy.

### 🧠 Dual-Engine Learning Architecture
1. **SLO Custom Notebooks (NotebookLM)**: Curated active-study notebooks synthesized directly from chapter-specific Student Learning Outcomes (SLOs), primary lecture notes, and lab objectives.
2. **Study & Learn Tutors (Gemini AI)**: Interactive, conversational Socratic tutors that guide students through conceptual mastery, clinical case studies, and active recall practice.

---

## ✨ Key Features

* 📚 **12 Comprehensive Chapter Modules**: Full coverage of BIOL 2401 curriculum from chemical levels to special senses.
* 🎯 **Lecture Exam Unit Mapping**: Filter chapters by Lecture Exams #1 through #4.
* ⏱️ **Live Fall 2026 Course Countdown**: Real-time clock and dynamic two-phase semester timer (counting down to August 24 start date, auto-transitioning to December 8 final exam target).
* 📊 **Local Progress Meter**: Real-time course completion tracking saved locally in the student's browser (`localStorage`).
* 🔍 **Smart Search & Resource Filters**: Instantly filter by topic keywords, exam units, or resource types (NotebookLM vs. Gemini Tutors).
* 📱 **Responsive & Accessible Design**: Modern, mobile-first design with high-contrast typography and smooth animations.

## 📅 Course Curriculum & Module Directory

| Module | Chapter Title | Lecture Exam Unit | Core Pedagogical Topics |
| :--- | :--- | :--- | :--- |
| **CH01** | Introduction to A&P | Lecture Exam #1 | Anatomical position, body planes, abdominopelvic regions, homeostasis & feedback loops |
| **CH02** | Chemical Level of Organization | Lecture Exam #1 | Chemical bonds, enzymes, pH scale, buffers, dehydration synthesis, hydrolysis |
| **CH03** | Cellular Level of Organization | Lecture Exam #1 | Plasma membrane, passive/active transport, organelles, mitosis & cell life cycle |
| **CH04** | Metabolism & Metabolic Reactions | Lecture Exam #2 | Cellular respiration (Glycolysis, Krebs, ETC), DNA/RNA, transcription, translation |
| **CH05** | Tissues (Histology) | Lecture Exam #2 | Epithelial, connective, muscle, nervous tissues; membranes & tissue repair |
| **CH06** | Integumentary System | Lecture Exam #2 | Epidermal layers, thin vs. thick skin, thermoregulation, burns, wound healing |
| **CH07** | Skeletal System: Bones | Lecture Exam #3 | Bone histology, endochondral/intramembranous ossification, calcium homeostasis |
| **CH08** | Skeletal System: Joints | Lecture Exam #3 | Joint classifications, synovial joint anatomy, lever systems, range of motion |
| **CH09** | Muscular System | Lecture Exam #3 | Neuromuscular junction, sliding filament theory, excitation-contraction coupling |
| **CH10** | Nervous System: Overview | Lecture Exam #4 | Neuroglia, resting membrane potential, action potential propagation, synapses |
| **CH11** | Nervous System: Divisions | Lecture Exam #4 | CNS/PNS divisions, brain anatomy, meninges, CSF flow, spinal cord tracts, reflexes |
| **CH12** | Somatic & Special Senses | Lecture Exam #4 | Receptors, sensory/motor pathways, vision, hearing, equilibrium, olfaction, gustation |

## 🚀 Deployment Guide

This project is fully static and ready for instant deployment on **Netlify** or **Vercel**.

### Deploying to Netlify
1. Fork or push this repository to your GitHub account.
2. Log in to [Netlify](https://www.netlify.com/).
3. Click **Add new site** $\rightarrow$ **Import an existing project**.
4. Choose **GitHub** and select `biol-2401-notebook-tutor`.
5. Netlify will automatically detect [netlify.toml](file:///c:/Users/skint/Desktop/4_AI%20carpetas%20y%20apps/01.%20Backed%20in%20GitHub/23-biol-2401-%20notebook-tutor/netlify.toml). Click **Deploy**.

### Deploying to Vercel
1. Log in to [Vercel](https://vercel.com/).
2. Click **Add New...** $\rightarrow$ **Project**.
3. Import the `biol-2401-notebook-tutor` GitHub repository.
4. Vercel will automatically load configuration settings from [vercel.json](file:///c:/Users/skint/Desktop/4_AI%20carpetas%20y%20apps/01.%20Backed%20in%20GitHub/23-biol-2401-%20notebook-tutor/vercel.json). Click **Deploy**.
